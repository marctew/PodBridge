API tokens

For displays, Docket, Home Assistant and scripts that read /api/v1.{% if api_tokens_apps %} An app that keeps its own items here (reminders from Muddy Paws, say) gets a token that belongs to it: only that app sees those items.{% endif %} Send Authorization: Bearer <token>; a display that can't set a header can put a read-only token in the URL as ?token=. Write tokens only work in the header. Give each screen or script its own token, so it can be revoked alone.
